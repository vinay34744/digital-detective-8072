# Mission 01 – Computer Basics

## Objective
Understand the fundamental components of a computer, how they work together, and the difference between hardware and software.

## 1. What is a Computer?

A computer is an electronic device that accepts data as input, processes it , stores information, and produces output.

## 2. Hardware

Hardware refers to the physical components of a computer that we can see and touch.

### Main Hardware Components

| Component | Function |
|---|---|
| CPU | Executes instructions and processes data |
| RAM | Temporarily stores data currently in use |
| HDD / SSD | Stores data permanently |
| Motherboard | Connects different computer components |
| GPU | Processes graphics and visual information |
| Monitor | Displays visual output |
| Keyboard |Used to enter text and commands |
| Mouse | Used to interact with the computer |

## 3. Software

Software is a collection of programs and instructions that tell a computer what to do.

### Types of Software

| Type | Description | Example |
|---|---|---|
| System Software | Manages computer hardware and resources | macOS, Windows, Linux |
| Application Software | Helps users perform specific tasks | Chrome, VS Code |
| Programming Software | Tools used to develop programs | Python, compilers |

## 4. Input, Processing, Output and Storage

A computer generally follows the IPOS cycle:

1. **Input:** Data is entered into the computer.
2. **Processing:** The CPU processes the input.
3. **Output:** The computer displays the result.
4. **Storage:** Data and results can be saved for future use.

## 5. Memory and Storage

| RAM | ROM | SSD / HDD |
|---|---|---|
| Temporary memory | Non-volatile memory | Long-term storage |
| Usually volatile | Non-volatile | Non-volatile |
| Stores active data | Stores firmware | Stores files and applications |

## 6. Operating Systems

An operating system is system software that manages hardware, software, files, memory, and user interactions.
Examples:
- macOS
- Windows
- Linux
- Android
- iOS

## 7. Practical Work
- Identified the basic components of a computer.
- Studied the difference between hardware and software.
- Understood the functions of CPU, RAM, and storage.
- Learned the IPO cycle.
- Explored operating system concepts.

## Learning Outcome
Understood the basic architecture of a computer, its major hardware components, 
different types of software, and how a computer processes and stores information.
