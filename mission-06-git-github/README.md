# Mission 06: Git and GitHub

## Objective
To understand version control and learn how to use Git and GitHub to manage and publish project files.

## What is Git?
Git is a version control system that tracks changes made to files. It helps developers save different versions of their projects and work together.

## What is GitHub?
GitHub is an online platform that hosts Git repositories. It allows developers to store code, share projects, and collaborate with others.

## Important Git Concepts

- **Repository:** A folder where Git tracks project files.
- **Commit:** A saved snapshot of changes.
- **Branch:** A separate line of development.
- **Remote:** An online repository connected to the local repository.
- **Push:** Upload local commits to GitHub.
- **Pull:** Download and integrate changes from GitHub.
- **Clone:** Copy a remote repository to a local computer.

## Important Git Commands

| Command | Purpose |
|---|---|
| `git init` | Initialize a Git repository |
| `git status` | Check file changes |
| `git add .` | Stage all changes |
| `git commit -m "message"` | Save changes as a commit |
| `git log` | View commit history |
| `git branch` | View branches |
| `git remote -v` | View connected remote repositories |
| `git push` | Upload commits to GitHub |
| `git pull` | Download and integrate remote changes |
| `git clone URL` | Copy a remote repository |
