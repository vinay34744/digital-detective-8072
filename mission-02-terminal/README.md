# Mission 02 – Terminal

## Objective
Learn how to use the command-line terminal to navigate directories, manage files, and execute basic system commands.

## Operating Environment
- **Operating System:** macOS
- **Shell:** Zsh
- **Terminal:** macOS Terminal

## Commands Learned

### 1. Directory Navigation
| Command | Purpose |
|---|---|
| `pwd` | Display the current working directory |
| `ls` | List files and directories |
| `ls -la` | List all files, including hidden files |
| `cd` | Change directory |
| `cd ..` | Move to the parent directory |
| `cd ~` | Move to the home directory |

### 2. File and Directory Management
| Command | Purpose |
|---|---|
| `mkdir` | Create a directory |
| `touch` | Create an empty file |
| `cp` | Copy files or directories |
| `mv` | Move or rename files |
| `rm` | Remove files |
| `rmdir` | Remove an empty directory |

### 3. File Content Commands
| Command | Purpose |
|---|---|
| `cat` | Display file contents |
| `less` | View file contents page by page |
| `head` | Display the first lines |
| `tail` | Display the last lines |
| `wc` | Count lines, words, and characters |

### 4. Searching and Permissions
| Command | Purpose |
|---|---|
| `find` | Search for files and directories |
| `grep` | Search for text patterns |
| `chmod` | Change file permissions |
| `which` | Locate an executable |

### 5. Other Useful Commands
| Command | Purpose |
|---|---|
| `clear` | Clear the terminal screen |
| `echo` | Display text |
| `whoami` | Display the current username |
| `man` | Display a command manual |
| `history` | Display previously executed commands |

## Important Concepts Learned

- Absolute and relative paths
- Parent and home directories
- Hidden files and directories
- Command options and flags
- File and directory permissions
- Command chaining and pipes (`|`)
- Output redirection (`>` and `>>`)

## Practical Work

Practised creating directories, navigating between folders, creating and viewing files, searching for files, and managing file permissions using terminal commands.

## Learning Outcome

Developed basic command-line skills and learned how to interact with the operating system through the terminal.
