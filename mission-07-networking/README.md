# Mission 07: Networking

## Objective
To understand the basics of computer networks and how computers communicate with each other over the internet.

## What is a Computer Network?
A computer network is a group of connected devices that communicate and share information and resources.

## Basic Networking Concepts

- **IP Address:** A numerical address used to identify a device on a network.
- **MAC Address:** A hardware address associated with a network interface.
- **DNS (Domain Name System):** Converts domain names, such as `google.com`, into IP addresses.
- **HTTP:** A protocol used to transfer web pages and other data.
- **HTTPS:** A secure version of HTTP that encrypts communication.
- **Router:** A device that forwards data between networks.
- **Server:** A computer or system that provides services or resources to other devices.
- **Client:** A device or application that requests services from a server.
- **Packet:** A small unit of data transmitted across a network.

## Types of Networks

- **LAN (Local Area Network):** Connects devices within a limited area, such as a home, office, or college.
- **WAN (Wide Area Network):** Connects networks over large geographical areas.
- **WLAN (Wireless Local Area Network):** A local network that uses wireless communication, usually Wi-Fi.

## How Does the Internet Work?

1. A user enters a website address in a browser.
2. DNS finds the IP address associated with the domain name.
3. The browser sends a request to the website's server.
4. The server processes the request and sends back a response.
5. The browser displays the website.

## Important Networking Terms

| Term | Meaning |
|---|---|
| Bandwidth | Maximum data transfer capacity |
| Latency | Time taken for data to travel |
| Protocol | Rules for communication |
| Firewall | Filters network traffic based on security rules |
| ISP | Internet Service Provider |

## Learning Outcome

Learned the basic concepts of computer networking, IP addresses, DNS, HTTP/HTTPS, routers, servers, clients, and how a browser communicates with a website.
