# Mission 04 – Programs

## Objective

Understand how computer programs work, how programming languages are used to give instructions to computers, and how to write and execute basic Python programs.

## 1. What is a Program?

A program is a set of instructions written in a programming language that tells a computer how to perform a particular task.

## 2. Programming Languages

Programming languages allow humans to communicate instructions to computers.

Examples:
- Python
- C
- C++
- Java
- JavaScript

## 3. Python Programming

Python is a high-level, interpreted programming language known for its readable syntax and wide range of applications.

### Basic Python Example

```python
print("Hello, World!")
```

Output:

```text
Hello, World!
```

## 4. Variables and Data Types

Variables store data that can be used in a program.

```python
name = "Vinay"
age = 18
height = 5.8
is_student = True
```

| Data Type | Description | Example |
|---|---|---|
| `int` | Integer numbers | `18` |
| `float` | Decimal numbers | `5.8` |
| `str` | Text | `"Vinay"` |
| `bool` | True or False | `True` |

## 5. Operators

Operators perform operations on values and variables.

| Operator | Purpose |
|---|---|
| `+` | Addition |
| `-` | Subtraction |
| `*` | Multiplication |
| `/` | Division |
| `//` | Floor division |
| `%` | Modulus |
| `**` | Exponentiation |
| `==` | Equal to |
| `!=` | Not equal to |

## 6. Conditional Statements

Conditional statements allow a program to make decisions.

```python
age = 18

if age >= 18:
    print("Eligible")
else:
    print("Not eligible")
```

## 7. Loops

Loops are used to execute a block of code repeatedly.

### For Loop

```python
for i in range(5):
    print(i)
```

### While Loop

```python
count = 1

while count <= 5:
    print(count)
    count += 1
```

## 8. Functions

Functions are reusable blocks of code designed to perform specific tasks.

```python
def greet(name):
    return "Hello " + name

print(greet("Vinay"))
```
